# TapNow 3D 导演台复刻 — 项目文档 / 交接

> 原站:`https://app.tapnow.media/canvas/2509f15e-c8ae-44e4-87b2-62f1da8220e3?chat_mode=agent` 内的「3D 片场」
> 复刻目录:`tapnow-studio-replica/`(独立 Vite + React 19 + Three.js r182 应用,不依赖原站)
> 依据文档:`../tapnow-3d-studio-功能面探查.md`(含第二轮二级菜单实测)、`../tapnow-3d-studio-界面架构.md`

## 1. 运行

```bash
cd tapnow-studio-replica
bun install            # 已装
bun x vite --port 5199 # 开发(当前在跑)
bunx tsc --noEmit      # 类型检查:0 错
bunx vite build        # 产物构建:通过
```

浏览器打开 `http://localhost:5199/`(默认直接进入片场;`返回` 可回到画布占位页)。

## 5. 已知限制

- 录制依赖浏览器 MediaRecorder:在无编码器的 Chromium 构建上会退化为空视频(已做默认构造 + 手动
  `requestFrame` 兼容,常规 Chrome/Edge 正常);低帧率环境下录制帧率随渲染帧率
- 「生成 3D 对象」无外部生成 API,等价实现为打开模型库(内置 18 种 + 上传 GLB)
- 「导出到画布」在复刻里没有画布节点,等价实现为导出镜头清单 JSON
- 全景图仅支持上传/应用,未做全景编辑(原站为独立编辑器)
- 原站账户画布内的「状态 2」是本次探查早期误点产生的,未删除(避免动用户数据)

## 7. 本轮改造(产品需求:去画布 / 机位体验 / 第一视角操控 / 三轨时间轴 / 性能 / 运镜打光)

### 7.1 去画布,故事板为唯一导出
- 删除 `CanvasStub.tsx` 与画布占位样式;`App.tsx` 直接渲染 `<Studio/>`。
- 顶栏移除「返回」;镜头管理面板导出按钮改为「导出到故事板」;全景图面板空态文案去掉「画布」。
- 快门照片 / 运镜录制视频全部进故事板。

### 7.2 机位进入平滑(进/出都有过渡)
- `ThreeStage` 新增 `viewBlend`(0→1,0.7s smoothstep)+ 进/出姿态快照。
- 点击摄像机芯片或「镜头管理」切机位:FOV、位置、注视点从当前自由视角插值到机位视角;Esc 退出时从机位姿态滑回进入前视角。
- 实测 blend 序列 0.12→1.00,退出同样平滑。

### 7.3 操控 = 被控体第一视角 WASD 驾驶
- 渲染相机在 `controlId` 时切到实体眼部(角色 0.88×身高、摄像机 1.28m、道具半高+0.25),FOV 75(摄像机按焦距)。
- WASD 以「被控体朝向」为正前(第一视角语义),Q/E 升降(机位/操控),Shift 加速。
- 角色步态:`buildHuman` 关节命名(hipL/R、kneeL/R、shoulderL/R、elbowL/R、pelvis);驾驶中髋/膝/肩/肘正弦摆动,松开缓回基准。
- 坐/躺姿角色进入操控会自动起身:骨盆高度插值到 0.47×身高、关节插值到站姿(0.5s),退出立即还原原姿态。

### 7.4 时间轴拆三轨
- 轨道:人物·对象 / 机位 / 打光;每轨独立菱形关键帧,点击跳转并选中对应对象;轨末「+」保存该轨关键帧。
- 打光轨:`lightKeys` 记录每盏灯的强度/颜色快照;播放时按关键帧插值(暂停即恢复 store 值);支持清空打光轨。
- 移除「测试版」徽标;「时间轴操作」菜单新增清空打光轨。

### 7.5 运镜 / 打光能力
- 运镜面板新增播放参数:速度 0.5×/1×/1.5×/2×、往返播放(来回一趟后自动停)。
- 灯光面板新增「打光关键帧」快捷保存(自动打开时间轴)+ 已存数量提示。

### 7.6 性能
- `pixelRatio` 上限 2 → 1.5(实测 buffer/client = 1.5)。
- `shadowMap.autoUpdate = false`:阴影贴图仅在场景结构、灯光、实体位姿、步态/起身、打光采样变化时重绘;静态帧不再重画阴影。
- 实测满帧 120fps(受 vsync 上限)。

### 7.7 调试探针(供回归)
`window.__studio_debug` 新增 `view`('free'|'cam'|'control')、`walk`、`blend`、`legs`、`pelvisY`、`jointGen`、`dt`、`phase`。

## 8. 增强轮(承接操控/起身机骨科/打光 id/示例状态/重放)

- **录制承接操控视角**:录制是 `renderer.domElement.captureStream(0)` + 主循环始终用 `renderCam` 渲染,操纵委以 FPV / 机位视角在录制时一并生动。实测 start/stop + 1.2s 走亅后获取 webm blob 并入故事板。
- **起身保留**:行走时骨盆在站姿上做 `|sin(walkPhase*2)| * 0.018` 的双频小幅弹跳,脚步节奏更一目了然;进入操控后仔骨高度自动在 0.5s 内过渡到站姿。
- **打光关键帧按灯 id 对齐**:灯光实体 userData.lightId;采样时按 id 值颜色/强度插值,增删灯不再错位。
- **默认示例状态**:`s-demo-walk`(人物移走+35mm 主机位焦)、`s-demo-multi`(多一个 B 机位 + 路灯 actor2 站)。
- **故事板重放**:video 且带 path 的镜伦「重放运镜」按钮,调用 store.runPath(path)。

### 最兵验证
- `tsc --noEmit` ✅;`build` ✅
- 实测:录制凭证 FPV;示例状态加 pang 切换;路径 speed/pingPong 实测生效;州味含摘除后按 id 采样。

## 9. 性能与专业功能轮

### 性能
- 像素比 1.5 → **1.25**(实测 buffer/client = 1.25)。
- **阴影只由第一盏启用灯(主光)投射**:其余填充/轮廓灯 `castShadow=false`,阴影贴图 2048/1024 → 1536(主光)/1024(其他)。
- **拾取节流**:pointermove 的 raycast 150ms 一次,不再每帧。
- **芯片投影静态跳过**:相机矩阵 + 选中 + 模式 + 播放状态 + 实体数 + 视口构成签名,且实体位姿无变化时不重投影(静态帧零开销)。

### 专业功能
- **取景器构图工具**:三分/十字/无网格切换、90%/80% 安全区、中心点标记。
- **相机状态条**(取景器顶部):焦距 / FOV / 光圈 / 快门 / ISO;机位模式下读当前摄像机的真实参数。
- **曝光三要素**:Entity 增加 `aperture/shutter/iso`;属性条新增「曝光」菜单(f/1.4–f/8、1/24–1/250、ISO100–1600)。
- **运镜缓动**:线性 / 缓入 / 缓出 / 缓入缓出(实测同刻位置各异)。
- **灯光预设 +2**:正午日光(日光+天光补光)、钨丝暖调(暖主光+冷轮廓+环境底子)。
- **故事板标注**:运镜视频徽标显示具体运镜类型(推镜/环绕等),并可一键重放。

### 验证
- `tsc --noEmit` ✅ `build` ✅
- 取景器 5 个开关实测生效;状态条 `24mm|FOV84°|f/2.8|1/50s|ISO400`,机位模式读 cam1 为 `32mm|FOV68°|f/1.4`
- 曝光菜单三组选项齐全,选择 f/1.4 落库
- 缓动 linear/inout/in 同刻相机位置差 1.11m(曲线生效)

## 10. 能力提升轮(调色/倍速/多机位/跟随对焦/走位)

- **色调映射与曝光**:设置面板可选 关闭 / ACES / Filmic / Reinhard + 曝光补偿 0.2–2.5×,直接驱动 `renderer.toneMapping` 与 `toneMappingExposure`。
- **时间轴倍速**:0.5×/1×/2×(时间轴操作菜单);同时移除 Timeline.tsx 里的第二套 rAF —— 播放推进统一由 ThreeStage 主循环驱动(此前是双推进隐患)。实测 1× 与墙钟 1:1、2× 恰好两倍。
- **多机位数字键**:按 1–9 直接切到第 N 台摄像机。
- **摄像机跟随与对焦距离**:属性条 → 更多操作 → 跟随目标(不跟随 / 各角色道具);取景器状态条新增「对焦 X.Xm」(跟随目标时 = 机位到目标距离,无目标显示 ∞)。
- **角色走位路径(blocking)**:属性条 → 走位路径 → 点地面加路点(Esc 结束),地面绘制黄线路点;时间轴播放时无关键帧的角色沿路径匀速行走并自动转向,且**带完整步态**(关节摆动 + 骨盆弹跳);可清除走位。
- **性能**:tick 内建 `id→entity` Map,去掉每帧多次 `find`;新增 `dbg.fps`(EMA)与设置里的「性能面板」开关(右上角 FPS 芯片)。

## 14. 直接操纵轮(TransformControls)

### 调研结论
单选实体后无法直接移动/旋转 —— 自研 gizmo 只是装饰。three.js 生态标准解是 `TransformControls`(官方控件,平移/旋转/缩放 + 吸附 + 拖拽事件),与自研轨道手势可共存(拖拽时互相抑制)。

### 实现
- **挂载**:选中实体且 3D 模式时 `tc.attach(group)`;模式切换 `gizmoMode`(store);旋转模式锁 Y 轴(showX/showZ=false),平移三轴(含 Y 垂直移动)。
- **吸附**:平移 0.25m、旋转 15°(`translationSnap`/`rotationSnap`)。
- **写回**:拖拽中 `objectChange` → `transformSilent`(静默 mutateEntity);tick 同步循环跳过拖拽中的实体(tc 权威);**mouseDown 压一次历史快照**,松手即完成 —— undo 一次回拖前。
- **手势互斥**:`onDown/onMove/onHover` 遇 `tc.dragging` 直接返回;`dragging-changed(true)` 取消进行中的轨道手势。
- **键位**:T 平移 / R 旋转;旧装饰三轴在 gizmo 挂载时隐藏。
- **精确数值编辑**:属性条新增 X/Y/Z/朝向° 四个紧凑输入框(Enter/失焦提交,进历史)。
- 快捷键帮助更新。

## 23. 取景(成片)视角纯净模式

**问题**:机位只是"视角选项",但在时间线的视频视角里,其它机位模型、机位标签、视锥、走位路径线、选中框、画中画监看窗全都入镜,画面不是成片。

**根因**:隐藏编辑辅助的判断 `fpView` 只认 `mode.type === 'cam' || controlId`,**不含镜头轨出画**(timeline 打开 + cut 命中)那条路径。

**修复**:把视角解析提前到每帧统一位置,得到 `viewActive = 镜头轨出画 | 手动机位 | 操控`,取景时:
- 隐藏所有机位实体模型(含正在出画的那台——它在镜头里)
- 隐藏走位路径线/路点(`blockingGroup`)
- 隐藏视锥助手与机位名 sprite(`syncFrustums` 读 `viewActiveNow`)
- 隐藏全部对象标签 chip(机位/角色/道具)
- 隐藏选中框、角色圆环与 TransformControls(改用 `viewActive`)
- **画中画监看窗只在手动驾驶机位时显示**(镜头轨成片不叠加其他机位画面)

退出取景(关时间轴 / 回自由视角)全部恢复;隐藏按需赋值且幂等,新建对象由每帧循环兜底。

**验证**(ego):
- 编辑视图 `cleanView=0 / chips=6`;取景 `cleanView=1 / chips=0 / cutCam=CAM1·CAM3`;退出恢复 `0 / 6`。
- 画中画:镜头轨出画时 `pip=""`;手动机位时 `pip="CAM2 跟拍"`(切台预览保留)。
- 视觉核验(CAM1/CAM3/CAM4 三帧):画面内无机位模型、无 3D 标签、无黄色路径线、无选中框、无画中画,只剩演员与摄影棚场景。

# 项目业务逻辑文档

目的：让后续维护者无需还原聊天记录、遍历所有组件或依赖原作者记忆，就能理解业务行为并验证迁移后的等价性。

## 位置与组织

- 优先沿用仓库已有业务文档目录和格式；没有约定时使用 `docs/business/`，按实际业务能力维护 Markdown 文档，以 `index.md` 提供简洁索引。
- 首次接入只记录当前任务涉及的业务，允许逐步完善。索引标明已覆盖和待补充范围，不假装已有全量梳理。
- 一个主题有一个权威说明，其他文档链接引用；不在架构说明、README、接口文档中重复维护同一份规则。
- AGENTS.md 维护业务文档索引及查阅要求，具体规则留在对应业务文档；项目指引维护遵循[维护 AGENTS.md](agents-md.md)。
- 文档随代码纳入版本管理。实现重要行为变化时在同一变更中更新，不只写在提交说明或聊天中。
- 单模块较小时先维护一份紧凑文档，不为模板预建空目录、空章节或独立规则平台。

## 必须表达的业务信息

按本次模块实际情况覆盖以下内容，没有相关概念的章节可以省略：

1. **业务目的与边界**：服务谁、完成什么、触发入口、与相邻模块的关系。
2. **领域概念与状态归属**：实体、标识、字段含义与单位；由谁维护事实，哪些是持久化数据、界面状态或可重建投影。
3. **规则与不变量**：前置条件、权限、校验、额度/预算、允许和禁止的操作；规则发生冲突时的优先关系。
4. **关键流程和状态转换**：触发 → 校验 → 计算/状态变化 → 外部副作用 → 持久化 → 用户反馈；列出真实执行顺序、完成判据和补偿方式，不假定所有流程都按此顺序。
5. **失败与并发行为**：错误、取消、超时、重试、幂等、重复提交、项目切换、多窗口及后台进程退出时的实际语义。
6. **数据和外部契约**：事件、检查点、IPC、MCP、网关、媒体及项目文件的必要结构、版本、兼容和迁移方式。
7. **行为示例和验证依据**：代表性输入、预期输出/状态/副作用，对应实现入口和测试路径，包含关键边界或失败例。
8. **迁移要求与未知项**：必须保持的行为、允许改变的实现、资源路径和宿主假设、历史数据样本、尚未确认的需求及验证缺口。

文档以业务语言解释行为。API 与 schema 已有权威定义时链接到源码，不复制会失真的完整类型；关键字段语义仍需说明。只对复杂流程使用小型 Mermaid 状态图或时序图，图与文字保持一致。

## 事实与证据

- 阅读真实调用链、领域用例、状态归约、适配器及相关测试；不能仅依据 UI 文案、类型名称或需求草图推断现状。
- 明确区分“当前实现”“期望行为”“已知缺陷”“待确认”，不要将计划和推测写成已实现规则。
- 需求、实现和测试不一致时明确记录差异，按用户已确认要求处理；不能为了文档一致而擅自改变业务。
- 未确认的价格、额度、重试次数、时间阈值和阶段定义不得编造；标明配置/数据的实际来源。
- 源码和测试引用使用仓库相对路径及稳定符号名。外部参考记录必要版本或提交；不只依靠容易漂移的行号定位。
- 示例使用合成或脱敏数据，不包含真实密钥、用户隐私或生产数据转储。
- 非显然的设计取舍记录原因、约束和重新评估条件；不要逐行复述代码或将当前框架细节当作永久业务规则。

## 随变更维护

- 开始工作先查相应文档，确认其与本次代码是否一致。
- 新增业务能力补充对应说明；修改规则、状态或契约时更新受影响章节，并同步相关测试/样本。
- 修复缺陷时说明正确规则，移除已解决的现状偏差；版本迁移所需历史语义保留在专门兼容说明中。
- 只修布局、文案或内部封装且不改变业务时，不机械添加“文档已更新”噪声；检查链接是否因移动代码而失效即可。
- 文档和实现一起评审。完成前核对相对链接、符号/测试是否真实存在，说明验证命令与结果；不要将测试路径存在当成测试通过。

## 用于后续迁移

- 迁移前从文档提取行为清单、数据兼容要求及失败语义，形成有对应测试或明确待验证项的验收依据。
- 文档中的规则与代表性示例映射到 Vitest 契约/回归测试和必要的真实 Electron 验证，避免只有文字承诺。
- 新实现使用相同输入样本验证规则与结果；有意改变的契约明确记录，不能直接以新实现结果覆盖原有预期。
- 区分业务不变量和技术实现：更换 React、Zustand、Electron、数据库或 SDK 时，能够指出哪些行为必须保持、哪些适配层可以重写。
- 记录数据迁移、降级/回退能力及不可逆限制，不因为有文档就宣称迁移已验证或可无损回滚。

## 简洁文档骨架

按需要采用，删除不适用章节，不将占位内容作为完成结果：

```markdown
# <业务能力>

## 目的与边界
## 概念、数据与状态归属
## 业务规则与不变量
## 关键流程与异常路径
## 数据契约与版本兼容
## 行为示例、实现入口与测试
## 迁移要求、已知差异与待确认事项
```

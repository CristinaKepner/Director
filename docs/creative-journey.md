# 创作路径

入口是现有舞台工具栏的「创作画布」。按 DirectorAgent/designs/exports 的正式 app-* 设计，采用全屏点阵节点画布、顶部运行条、底部音画控制器，仍是同一工程中的工作模式；「拍摄 · 剪辑」返回原有工作区。整体维持紫色。

画布按参照 → 画面 → 决策 → 生成 → 检查 → 产物排列。可拖空白平移、缩放、适合视图、切换点阵/网格。点击节点或底部镜头打开检查器；旁白、配乐、音效可直接从时间线改开始时间、长度、素材入点和音量。两侧 Director 与决策面板默认收起，原聊天输入在浮动输入条与 Director 面板之间复用，保留聊天、模型选择和工具绑定。

节点工具箱接到现有的参照、镜头、音轨、细化、预演、质量检查和剪辑功能；画布聚焦时按 Tab 打开。当前节点是工程依赖的可视图，尚不是支持任意连线的工作流执行器。Summary 展示当前路径，可回到检查点重新选择；决策面板展示其他分支、未选方案、来源和版本对照。状态取自真实工程/任务，不展示虚构费用、模型进度或质量检查结果。

用户可以输入一个印象，选择 20 / 30 / 60 / 120 / 180 秒及画幅。已有工程先保存为「原始工程」，默认可沿用现有镜头。方向卡片提供叙事、节奏、声音三次单维度选择；每次选择是决策树中的一个子节点。每镜可直接改标题、画面、旁白、时长和景别。连接文字模型后，可细化出具体脚本候选；必须预览并采用后才替换。

## 决策与恢复

`journey.nodes` 保存 parentId、选择、备选、理由、时间、来源、工程快照和当前分支的导演对话。`journey.head` 指向当前检查点。切换前自动保存未设检查点的修改，恢复时重设当前分支对话并清理待执行提案。画面、镜头、字幕、声音和媒体选择随检查点恢复，资产、外部任务记录共享。普通撤销不删除运行记录；跨分支使用决策树，切换时清空局部撤销栈。

这是检查点快照机制，不宣称完整事件重放。两版对照使用同一个播放头展示构图、脚本、旁白文本和节奏；它不是最终视频双播放器。

## 可播放的音画分镜

`journey.render` 把浏览器构图草图、当前脚本与声音选择交给本机 FFmpeg。macOS `say` 生成临时旁白，原创合成音调生成氛围配乐。视频、旁白、音乐保留为单独媒体，最终合成一个带字幕和声音的 MP4 预演。配音过长、文件缺失或工具不可用会明确报错，原片段保留。

这些是明确标注的构图草图和临时声音，不是图像/视频模型生成的写实影片。草图是内置示意构图，主要表现景别、人物关系与少量主题环境，并不忠实重现自由文本中的每个动作。更精细的画面仍通过原有模型生成 / 素材替换流程完成。

渲染和文字细化都记录开始时的 projectId、nodeId 和内容签名。离开分支或编辑内容后，异步结果保留为候选，不覆盖当前工程。回到其原检查点可采用；编辑后的分支需要重新制作。应用中断时任务标为失败，可显式重试，不暗中重复提交模型。

## 独立声音片段

`project.audioClips`：`{id, track: voice|music|sfx, url, label, start, duration, sourceIn, volume, muted}`。时间基于整片，可跨镜头。底部时间线可导入录音/音乐、设置入点、开始时间、长度、音量和静音；支持撤销。原 `cutMusic` 兼容保留。预览按全片时间同步声音；导出使用 atrim / adelay / amix，并应用峰值限制。

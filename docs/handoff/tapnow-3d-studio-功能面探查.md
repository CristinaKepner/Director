## 0. 入口

画布中央存在「3D 片场」节点卡片,带标题文本框(`请输入标题`,默认值"3D 片场")和「进入片场」按钮。点击「进入片场」后进入 3D 导演台全屏编辑态;顶部出现「返回」按钮可退出回画布。

## 1. 顶部区域

| 控件 | 类型 | 交互结果(已实测) |
|---|---|---|
| 返回(左箭头) | 按钮 `aria-label=返回` | 退出导演台回到画布,「3D 片场」节点恢复原卡片形态;场景内对象数量与进入前一致 |

## 2. 左侧焦距控件

- 竖向刻度尺 + `output` 显示当前 `24 mm`。
- 8 档位按钮:**8mm / 16mm / 24mm / 35mm / 50mm / 85mm / 135mm / 400mm**。
- 实测:点击 8mm 后 `output` 立即变为 `8 mm`,点击 24mm 恢复。切换为即时状态更新(可走 DOM 验证)。

## 3. 中央 3D 视口与场景对象芯片

视口为 WebGL 场景(树、2 名坐姿角色、白立方体、4 台摄像机),场景实体以 DOM overlay 芯片标注,可点击选中:

| 芯片按钮 | aria-label | 实测效果 |
|---|---|---|
| 摄像机 1–4 | `摄像机 N` | 进入该摄像机操控模式:底部"模式"按钮由 `3D` 变为 `摄像机 N`,场景内出现"操控摄像机"提示条,选中芯片处出现黄色状态点 + "…"更多菜单 |
| 角色 / 角色 2 | `角色` 系列 | 角色被橙色高亮选中;悬浮提示"聚焦 F""操控角色 C"、顶部提示"双击角色可以围绕它查看";底部出现对象属性条:**高 1.7 m、地坐(姿态)** 等 |
| 立方体、树 | 同名 | 同类选中语义(选中后出现对象属性条) |

通用对象选中后属性条(以"岩石"放置态实测确认):**名称 / 高度(高 -- m)/ 颜色 / 锁定(L)/ 更多操作(…)**。

「更多操作(…)」菜单实测项:
`名称、聚焦 F、操控 C、落到地面 G、恢复初始摆放、复制、锁定 L、从场景移除 (Del/Backspace)`。

# 第三轮(2026-09-09):空白场地观感 + 白模资产 + 品牌去除

## C1. 空白场地(超平坦)的真实观感(实测)
- 背景:**纯黑**(#050505 反正),无渐变、无雾
- 地面:深灰近黑(#161616),均匀低调
- 网格:浅色透视网格线铺满地面、延伸感强(原站「网格」开关默认开)
- 场景内容:中心一棵**茂密深绿大树**(多层低多边形叶冠+棕色多分叉树干+黑色地面阴影为主)+ 两个坐姿角色(浅蓝直接坐地、粉红坐在白色立方体上)+ 四周四台黑灰色的三脚架摄像机 + 深色 pin 形芯片(白色图标)
- 光照:顶部朝前的角色光照区域集中,其他地方地面偏暗 → 中心侧视 + 低环境光

## C2. 复刻版对应实现
- 空白场地/黑背景/网格线均已对齐(`bg #050505`、`floor #1c1c1c` + 阴影承接面、`GridHelper` 满铺)
- 树:自研的「密集多层密叶球 + 多分叉棕色树干」程序化生成(不再依赖 GLB),无缝隙、深绿色

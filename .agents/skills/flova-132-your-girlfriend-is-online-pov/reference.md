Process Planning:

Pre-check:Users must provide at least one of the following; otherwise, request it from the user immediately and do not proceed:

A reference image (female portrait / cute small animal / cute IP character, with a clear face or subject), or

A short piece of scene text (e.g., "walking on a rainy night", "feeding at home").

Subject Type Determination (Prioritize if an image is uploaded):

Determine the subject type of the uploaded image, categorized into three types: Female Portrait, Cute Small Animal, and Cute IP Character (including cartoons, plush toys, virtual characters, etc.).

If the subject is determined to be a male portrait, abort immediately, and politely inform the user that this Skill does not support male subjects and ask them to re-upload a suitable reference image.

Write the determination result into the "Subject Type" field of Final_Video_Spec.md, and all subsequent stages will adjust generation strategies based on this field.

Female Lead Character Locking and Character Sheet Generation → resource_prepare_and_analyze + media_generator

If the user uploaded a reference image: First, call resource_prepare_and_analyze to determine if the uploaded image is already in a 'half-body close-up + three-view' composite format (i.e., containing a half-body close-up and three full-body views: front/side/back):

It is a three-view composite format: Directly register the asset_id of the image, and also register the ①half-body close-up partition separately as an asset_id, binding all to key_element (female lead character element), no need to re-generate.

It is not a three-view composite format (e.g., single portrait, half-body photo, lifestyle photo, etc.): Call resource_prepare_and_analyze to extract visual features, then call media_generator (ImageToImage, Nano Banana Pro, 2K) to generate a '1 half-body close-up + 3 views' four-image horizontal composite sheet at once (① large half-body close-up / ② full-body front / ③ full-body side / ④ full-body back, solid white background, realistic portrait style). Only generate this one composite sheet; do not generate separate half-body images additionally. Register the asset_id for the entire sheet and register the ①half-body close-up partition separately as an asset_id, binding all to key_element (female lead character element).

If the user only provides text descriptions: Call media_generator (TextToImage, Nano Banana Pro, 2K) to directly generate a '1 half-body close-up + 3 views' four-image horizontal composite sheet. The registration method is the same as above; do not generate separate half-body images additionally.

Scene reference image (if provided by the user): Call resource_prepare_and_analyze to extract scene lighting and spatial features, register the asset_id, and bind it to key_element (scene element). 【Mandatory Pause Point 2】 Send the character sheet (including half-body close-up + three views) to the user for confirmation. Asset Analysis:

Subject Type Determination (Prioritize if an image is uploaded; results are written to the 'Subject Type' field in Final_Video_Spec.md):

Female Portrait: Enter the standard visual feature extraction process (see items 1–5 below).

Cute Small Animal: Extract species, coat color/pattern, body proportions, facial expression (eye size and shape, ear shape, nose shape), fur texture, and output as structured descriptions for character sheet generation.

Cute IP Character (including cartoons, plush toys, virtual characters, etc.): Extract styling style (realistic/cartoon/Q-version), main color tone and color scheme, iconic appearance features (ears, expressions, clothing props), material texture (fabric/plastic/plush), and output as structured descriptions.

Male Portrait: Terminate immediately and politely inform the user that it is not supported and ask the user to re-upload.

Visual Feature Extraction Specification (Applicable to Female Portraits):

Face and Makeup: Identify facial feature proportions, skin tone, makeup style (e.g., 'clear no-makeup look', 'tipsy pure-desire makeup', 'natural nude makeup'), extract key facial features (eye shape, lip shape, eyebrow shape, eye corner inclination).

Hair and Hairstyle: Identify hair status (e.g., 'slightly curly wet hair', 'air bangs', 'middle-part long straight hair'), hair color and gloss.

Clothing and Material: Identify current visible clothing style and fabric texture (e.g., 'coarse knit sweater', 'silk camisole', 'loose white shirt').

Light and Shadow and Color Temperature: Infer main light source direction and color temperature (e.g., 'golden hour side backlighting', 'soft diffuse light by the window', 'low-key cool white light indoors'), extract as scene tone descriptors.

Emotional Tone: Determine current emotional state (shy, proactive, lazy, playful, focused) and eye contact relationship with the lens (direct/looking back/downcast).

Scene Image Special (if it is a scene reference image): Extract spatial type, main light source, color temperature, depth of field texture, key props and background elements, output as structured phrases that can be directly written into Shot List scene descriptions.

Blank Auto-completion: If user input is minimal (e.g., just 'Good morning'), automatically fill in sensory details (sunlight, bed, messy hair, lazy stretching, warm breathing), filling in the corresponding blank fields in Final_Video_Spec.md.

Three-View Composite Layout Determination Rules (Prioritize if an image is uploaded): Determine if the uploaded image is already in a 'half-body close-up + three-view' composite layout format—i.e., the same image contains: ① half-body close-up area, ② full-body front, ③ full-body side, ④ full-body back, four partitions. If yes, output the conclusion 'Already in composite format, no need to re-generate', and label the position of each partition; if not, output 'Not a composite format, need to re-generate character sheet', and enter the visual feature extraction process.

Character Sheet Generation Input Specification: The extracted results must cover all stable features sufficient to drive the '1 half-body close-up + 3 views' four-image composite—face locking description (reproducible lip shape, eye shape, skin tone phrases) + hairstyle status + full clothing description (including color, material, fit, key details) + main light source tone. This structured output is passed directly to media_generator to generate the ① half-body close-up / ② full-body front / ③ full-body side / ④ full-body back four-image composite character sheet.

Text Theme Parsing Rules (Enabled when input is pure text):

Context Type Recognition: Judge core scene type from keywords—'Daily Warmth' (kitchen/sofa/bedroom/good morning), 'Outdoor Romance' (street/beach/tree-lined path), 'Tipsy Night' (KTV/bar/night neon), 'Ambiguous/Spirited' (bathroom/bedroom at night).

Emotional Tone Anchoring: Determine the female lead's preset emotional state (shy, proactive, lazy, playful) and initial eye contact relationship with the lens.

Blank Variable Auto-fill: If the user only provides minimal words (e.g., 'beach'), auto-complete: light source (sunset backlighting/soft water reflection), ambient sound (white noise of waves/sea breeze), clothing inference (loose chiffon dress/beach casual wear), temperature sensation (sea breeze blowing hair, sensation of stepping on fine sand). Trigger threshold: Force start when user input is less than 10 characters.

Output Format: Structured text, listed in items, can be directly reused for storyboard_designer and write_media_prompt. Do not directly use the extracted results as prompts for generating images; they must be integrated into the Shot List before writing prompts.
